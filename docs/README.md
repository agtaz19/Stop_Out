# Docs

The design lives in two shared artifacts. They are the source of truth, and this folder links to them rather than copying them.

| Document | What it holds |
| --- | --- |
| [Stop-Out: Game Design Spec](https://claude.ai/artifact/2QjkGqc7zLxyutMdHuRNLQ) | Session flow, formats, episodes, capital, roles, scoring, auctions, market agents, collusion controls, surveillance, decisions log |
| [Engine spec tab](https://claude.ai/artifact/2QjkGqc7zLxyutMdHuRNLQ#2ae9412c-4394) | Every formula, role events, margin and blow-ups, rotation, dropouts, ties, facilitator console, player rules sheet, fund cards, screens, data handling, prep kit |
| [Stop-Out Screen Mockups](https://claude.ai/artifact/2TAvXw4j64N63stD9ECHpz) | Phone, shared monitor, and facilitator screens in FQE formatting |

Both are private until their owner shares them. To keep a dated snapshot here, export each spec tab to Markdown from the doc's Share menu and save it as `docs/Stop_Out-Game_Design_Spec-YYYYMMDD.md` or `docs/Stop_Out-Engine_Spec-YYYYMMDD.md`.

[ROADMAP.md](ROADMAP.md) tracks the build phases.
